CelebPlan AI is an editorial, luxury celebration and event planning atelier designed to coordinate weddings, milestone birthdays, anniversaries, community galas, and corporate ceremonies. Powered by Generative AI (`meta/llama-3.1-70b-instruct`) and backed by Neon Serverless PostgreSQL with sub-millisecond composite indexing, it provides intelligent budget optimization, automated vendor checklists, structured day-of run-of-show generation, and guest RSVP tracking.

## 🚀 Key Features

### 1. 🤖 GenAI-Powered Planning Assistant & Structured Ingestion
- **Interactive Contextual Concierge (`/chat` & `/events/[id]`)**: Chatbot with 10-message sliding window memory ingesting celebration metadata, budget figures, and vendor status to deliver contextual guidance.
- **✨ AI Auto-Draft Run-of-Show (`/api/events/[id]/timeline/generate`)**: Produces structured JSON milestones that the application parses directly into database rows on the interactive itinerary, moving beyond plain prose.
- **Tuned Token Ceilings (`TOKEN_BUDGETS`)**: Strict per-operation token quotas (500–1500 tokens) to minimize latency, eliminate unnecessary token spend, and ensure predictable throughput.

### 2. 💰 Smart Budget Management
- Track estimated versus actual expenditures across venue, catering, decor, entertainment, and attire.
- Real-time remaining buffer calculation to prevent unexpected overspending with cached sub-millisecond currency formatters.
- Category breakdowns and cost-saving advice generated by AI.

### 3. 📋 Vendor Checklists & Contract Tracking
- Comprehensive vendor directory covering Catering, Photography, Music/DJ, Florists, and Rentals.
- Track negotiation status (`pending`, `contacted`, `booked`, `confirmed`).
- Pre-populated questions to ask vendors before signing contracts.

### 4. ⏰ Dynamic Day-of Run-of-Show Timelines
- Hourly milestone tracking for ceremonies, cocktail hours, speeches, and departures.
- Optimistic UI slice updates: mutations append or patch local state immediately without triggering full 6-table database re-fetches.

### 5. 👥 Guest List & RSVP Management
- Track confirmed, pending, and declined attendees with dietary flags (Vegan, Gluten-free, Halal) and +1 permissions.

## 🧠 GenAI Utilization Details

CelebPlan AI utilizes the **NVIDIA API** running `meta/llama-3.1-70b-instruct`: 
1. **Interactive Event Chat (`/api/chat`)**: Context-aware planning assistant that injects the current event's budget, date, vendor list, and tasks to provide deeply customized advice (capped at 800 tokens).
2. **Structured Timeline Engine (`generateStructuredTimeline`)**: Prompts the LLM for strict JSON milestone arrays, validated and inserted into the Postgres `timeline_items` table (capped at 600 tokens).
3. **Automated Event Plan Generator (`generateEventPlan`)**: Transforms raw parameters (event type, budget, guest count) into an end-to-end event strategy including milestone checklists (capped at 1500 tokens).
4. **Vendor Suggestions Engine (`generateVendorSuggestions`)**: Recommends appropriate vendor allocations and specific interview questions based on event scale (capped at 600 tokens).
5. **Budget Optimizer (`generateBudgetAdvice`)**: Identifies over-allocated categories and suggests practical cost-reduction tactics (capped at 500 tokens).

## 🔒 Security, Performance & Accessibility

- **Security & Multi-Tenant Isolation**:
  - Secure Bcrypt password hashing (cost factor 12).
  - JWT tokens stored in tamper-proof `HttpOnly`, `SameSite=Lax`, and `Secure` cookies.
  - Multi-tenant event ownership verification on every child route (`vendors`, `tasks`, `budget`, `guests`, `timeline`).
  - Parameterized PostgreSQL queries preventing SQL injection vulnerabilities.
  - Strict input sanitization removing malicious `<script>` and inline event handler payloads.
  - Comprehensive HTTP security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`).

- **Efficiency & Performance**:
  - 9 Neon PostgreSQL composite indexes (`idx_events_user_id`, `idx_vendors_event_id`, `idx_tasks_priority`, etc.).
  - Zero-allocation cached `Intl.NumberFormat` and `Intl.DateTimeFormat` formatters.
  - React `useMemo` hooks for budget ledger and task computations.
  - Next.js 15 static asset immutable headers (`max-age=31536000`) and API `no-store` headers.

- **Accessibility & UX Boundaries**:
  - Semantic HTML landmarks (`<nav>`, `<main>`, `<section>`, `<footer>`, `<dialog>`).
  - WCAG-compliant keyboard focus indicators (`focus-visible:outline`).
  - Accessible modal dialogs with focus trap and `Escape` key listeners.
  - ARIA attributes (`aria-invalid`, `aria-describedby`, `aria-live`, `aria-busy`) across all forms.
  - App Router resilience boundaries: `error.tsx` (crash recovery), `loading.tsx` (accessible skeleton), and `not-found.tsx`.

## 🏃 Local Setup & Installation

### Prerequisites
- Node.js (v18+)
- Active Neon PostgreSQL Database
- NVIDIA API Key

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/SabarishR08/celebration-event-planner.git
   cd celebration-event-planner
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env.local` and add your credentials:
   ```env
   DATABASE_URL=your_neon_postgres_connection_string
   NVIDIA_API_KEY=your_nvidia_api_key
   NVIDIA_API_BASE=https://integrate.api.nvidia.com/v1
   NVIDIA_MODEL=meta/llama-3.1-70b-instruct
   JWT_SECRET=your_jwt_secret_key
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to start planning your celebrations!

5. **Run Tests:**
   ```bash
   npm test
   ```
