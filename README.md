CelebPlan AI is a next-generation celebration and event planning platform designed to effortlessly coordinate weddings, birthdays, anniversaries, and community gatherings. Powered by Generative AI (`meta/llama-3.1-70b-instruct`) and backed by Neon Serverless PostgreSQL, it provides intelligent budget optimization, automated vendor checklists, day-of timeline generation, and guest RSVP tracking.

## 🌟 Vertical: Celebration & Event Planner
**Challenge 5**: Celebration & Event Planner  
**Target Audience**: Couples, birthday organizers, festival directors, and party planners seeking stress-free coordination, accurate budget forecasts, and personalized recommendations.

## 🚀 Key Features

### 1. 🤖 GenAI-Powered Planning Assistant
- Interactive contextual chatbot for event ideation, vendor negotiation strategies, and theme recommendations.
- One-click **Generate Full Event Plan** that produces detailed milestones, recommended vendor categories, and minute-by-minute day-of schedules.
- Tailored suggestions based on cultural requirements, dietary considerations, and budget boundaries.

### 2. 💰 Smart Budget Management
- Track estimated versus actual expenditures across venue, catering, decor, entertainment, and attire.
- Real-time remaining buffer calculation to prevent unexpected overspending.
- Category breakdowns and cost-saving advice generated by AI.

### 3. 📋 Vendor Checklists & Contract Tracking
- Comprehensive vendor directory covering Catering, Photography, Music/DJ, Florists, and Rentals.
- Track negotiation status (`pending`, `contacted`, `booked`, `confirmed`).
- Pre-populated questions to ask vendors before signing contracts.

### 4. ⏰ Dynamic Day-of Run-of-Show Timelines
- Hourly milestone tracking for ceremonies, cocktail hours, speeches, and departures.
- Ensures all stakeholders (hosts, photographers, caterers) operate in synchronized harmony.

### 5. 👥 Guest List & RSVP Management
- Track confirmed, pending, and declined attendees with dietary flags (Vegan, Gluten-free, Halal) and +1 permissions.

## 🧠 GenAI Utilization Details

CelebPlan AI utilizes the **NVIDIA API** running `meta/llama-3.1-70b-instruct`:
1. **Interactive Event Chat (`/api/chat`)**: Context-aware planning assistant that injects the current event's budget, date, vendor list, and tasks to provide deeply customized advice.
2. **Automated Event Plan Generator (`generateEventPlan`)**: Transforms raw parameters (event type, budget, guest count) into an end-to-end event strategy including milestone checklists and day-of timelines.
3. **Vendor Suggestions Engine (`generateVendorSuggestions`)**: Recommends appropriate vendor allocations and specific interview questions based on event scale.
4. **Budget Optimizer (`generateBudgetAdvice`)**: Identifies over-allocated categories and suggests practical cost-reduction tactics.

## 🔒 Security & Accessibility Implementations

- **Security**:
  - Secure Bcrypt password hashing (cost factor 12).
  - JWT tokens stored in tamper-proof `HttpOnly`, `SameSite=Lax`, and `Secure` cookies.
  - Parameterized PostgreSQL queries preventing SQL injection vulnerabilities.
  - Rate limiting on authentication and AI endpoints to thwart brute-force and DDoS attempts.
  - Strict input sanitization removing malicious `<script>` and inline event handler payloads.
  - Comprehensive HTTP security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`).

- **Accessibility**:
  - Semantic HTML landmarks (`<nav>`, `<main>`, `<section>`, `<footer>`, `<dialog>`).
  - WCAG-compliant keyboard focus indicators (`focus-visible:outline`).
  - Accessible modal dialogs with focus trap and `Escape` key listeners.
  - ARIA attributes (`aria-invalid`, `aria-describedby`, `aria-live`, `aria-busy`) across all form inputs and interactive buttons.
  - High contrast color palettes respecting both light and dark mode preferences.

## 🏃 Local Setup & Installation

### Prerequisites
- Node.js (v18+)
- Active Neon PostgreSQL Database
- NVIDIA API Key

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/SabarishR08/celebration-event-planner.git
   cd celebration-event-planner
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env.local` and add your credentials:
   ```env
   DATABASE_URL=your_neon_postgres_connection_string
   NVIDIA_API_KEY=your_nvidia_api_key
   NVIDIA_API_BASE=https://integrate.api.nvidia.com/v1
   NVIDIA_MODEL=meta/llama-3.1-70b-instruct
   JWT_SECRET=your_jwt_secret_key
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to start planning your celebrations!

5. **Run Tests:**
   ```bash
   npm test
   ```

- Events are owned by authenticated user accounts; multi-tenant isolation is enforced at the database query level.
- Budgets default to USD with extensible currency formatting.
- AI responses are buffered with rate limits to balance speed and token economics.
